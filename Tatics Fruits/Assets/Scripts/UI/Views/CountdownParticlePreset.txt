COUNTDOWN PARTICLE SYSTEM - QUICK SETUP PRESET
==============================================

Copy these settings to your Particle System component on:
/Canvas/Countdown/Particle System

MAIN MODULE
-----------
Duration: 0.5
Looping: OFF
Start Delay: 0
Start Lifetime: 0.8
Start Speed: 200
Start Size: 30
Start Rotation: Random between 0 and 360
Start Color: Gradient (White → Cyan → White)
Gravity Modifier: 0
Simulation Space: World
Play On Awake: OFF ⚠️ IMPORTANT
Max Particles: 50

EMISSION MODULE (✓ ENABLED)
----------------------------
Rate over Time: 0
Bursts:
  - Time: 0.0
  - Count: 40
  - Cycles: 1
  - Interval: 0.01
  - Probability: 1

SHAPE MODULE (✓ ENABLED)
-------------------------
Shape: Circle
Radius: 80
Radius Thickness: 0 (emit from edge) or 1 (emit from full circle)
Arc: 360
Emit from Edge
Random Direction: OFF

COLOR OVER LIFETIME (✓ ENABLED)
--------------------------------
Color Gradient:
  0%   → White, Alpha 100%
  70%  → White, Alpha 100%
  100% → White, Alpha 0%

SIZE OVER LIFETIME (✓ ENABLED)
-------------------------------
Separate Axes: OFF
Size Curve:
  0%   → 1.0
  50%  → 1.2 (particles grow slightly)
  100% → 0.0 (shrink to nothing)

VELOCITY OVER LIFETIME (✓ ENABLED) - Optional
----------------------------------------------
Linear:
  X: Random between -50 and 50
  Y: Random between 50 and 150 (upward)
  Z: 0
Space: World

ROTATION OVER LIFETIME (✓ ENABLED) - Optional
----------------------------------------------
Angular Velocity: Random between -180 and 180 degrees/sec

RENDERER
--------
Render Mode: Billboard
Material: Default-Particle (or create custom)
Sorting Fudge: 0
Min Particle Size: 0
Max Particle Size: 0.5
Sorting Layer: Default (same as UI)

TRAILS (✗ DISABLED) - Optional, can enable for more effect
-----------------------------------------------------------
If you want particle trails:
  - Ratio: 0.5
  - Lifetime: 0.3
  - Minimum Vertex Distance: 0.2
  - Color over Lifetime: Fade to transparent
  - Width over Trail: 1 → 0

==============================================
COLOR SUGGESTIONS FOR PARTICLES
==============================================

Option 1: Rainbow Burst
  - Start Color: Random between gradient
    Red → Orange → Yellow → Green → Cyan → Blue

Option 2: Match Countdown Colors
  - Use same colors as countdown (will change each time)
  - Or use white and let background glow provide color

Option 3: Cyan/White (recommended)
  - Pure white particles that match the "GO!" energy
  - Bright and visible against any background

==============================================
PERFORMANCE NOTES
==============================================

Mobile Optimization:
  - Max Particles: 30-40 (instead of 50)
  - Start Size: 20-25 (smaller)
  - Reduce emission count to 25-30
  - Disable Velocity/Rotation modules if needed

High-End:
  - Max Particles: 100-150
  - Add multiple particle systems (inner + outer rings)
  - Enable trails for more drama
  - Add glow material

==============================================
TESTING
==============================================

1. Select the Particle System GameObject
2. In Scene view, click "Simulate" in the Particle System component
3. Observe the burst pattern
4. Adjust settings in real-time
5. When satisfied, turn off "Simulate"
6. Test in Play Mode to see it triggered by script

Remember: The script calls burstParticles.Play() only on "GO!" step
